# 🧮 Switch Calculator

A modern calculator built using HTML, CSS, and JavaScript.

## Features

- ➕ Addition
- ➖ Subtraction
- ✖ Multiplication
- ➗ Division
- ❌ Divide by Zero Handling
- 🔄 Reset Button
- ⌨ Enter Key Support
- 📱 Responsive Design
- 🎨 Modern Glassmorphism UI

## Technologies Used

- HTML5
- CSS3
- JavaScript (Switch Case)
